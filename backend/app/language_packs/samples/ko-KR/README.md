# Korean M01 sample inputs

These scene and vocabulary files are local demo inputs only. They are AI-authored,
unreviewed data and are not part of the language pack or production vocabulary.
Do not treat their `catalog` provenance as a content review claim.

`scene.json` holds the same confirmed facts as the Spanish sample (a red cup on a table
and a green book) without handwritten plans, so `generate` uses the automatic M01 plan.
`vocabulary.json` covers those facts and every fact referenced by this pack's held-out
evaluation cases. Nouns list their particle/copula forms (컵이, 컵은, 컵도, 컵이에요) so
evaluation sentences can be matched word by word.
