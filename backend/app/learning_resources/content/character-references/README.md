# Character references

Create language folders only for writing systems that need a reference. A guide is
shared across missions; individual cheatsheet concepts link to relevant section IDs.

Example path for the first Korean guide:

```text
ko/ko-hangul.toml
```

Use the schema in `app/schemas/learning_resources.py`. A later version uses a suffix,
for example `ko/ko-hangul-2.toml`; cheatsheets explicitly select the version they use.
