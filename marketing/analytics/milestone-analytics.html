Milestone: Embed analytics and learn from the data

We embedded Contentsquare in the Linguini web app on 23 September 2026. It records pageviews, route changes, time on page, scroll depth and navigation paths. We use it to answer one question: does Home send learners into a photo lesson?

Set-up and checks

  • Tag: one async script in frontend/index.html, so every screen of the single-page app loads it.
  • Pages: we map two page groups, Home (/home) and Practice (/practice), where a learner picks or uploads a photo.
  • Route changes: sessions average 5–6 pageviews and the journey report shows Home → Practice → Home paths inside a single visit. So client-side navigation is recorded as separate pageviews, not only the first page load.
  • Live check: before relying on the report, we opened the realtime view and confirmed that moving from Home to Practice in the app appeared there as a new pageview.

Insight 1: Home held attention but did not lead anywhere, so we redesigned it

The old Home had a welcome, a “Today’s plan” card and a total XP count. Learners scrolled all of it (93% scroll rate) but spent only 2.4 seconds of a 46-second visit interacting with it: there was little on it about their own progress. On 24 September we redesigned Home as a personal dashboard, with a seven-day streak rail, a daily chart of words learnt and one featured “start or continue” card. What we take from it: the learner-specific stats work as intended. People read their streak and words learnt, and they stay about 70% longer. But the activity rate fell and the exit rate tripled: more of the extra time is spent reading, and one Home view in three now ends the visit. The dashboard is interesting, but it is not yet sending learners on to the next lesson.

Decision: keep the dashboard, but make the featured “start a photo lesson” card the first thing on screen, above the stats, and judge the next version on the Home → Practice rate and the Home exit rate instead of time on page. More time on Home is only good if learners then start a lesson.

Insight 2: Four in ten learners go from Home straight to a lesson

We used the journey report on the 23 sessions that started on Home to see where learners go next:

Decision: 39% is our baseline for Home → Practice, and the change in Insight 1 should raise it. The 30% going to unmapped pages is a gap in our tracking. We will add page groups for Journal, Vocabulary, Analysis, Learn and I-Spy, and a goal for “finished a photo lesson”, so the next report shows the whole learning loop as a funnel.

Insight 3: Mobile sessions are a third as long as desktop

Linguini is photo-led, so the phone should be its main device. Yet mobile visits last 2 minutes 9 seconds against 6 minutes 24 seconds on desktop, and bounce more (70% against 58%).

Decision: test the full loop on a phone every week and fix mobile layout first. On 25 September we already stacked the task and word-relation rows on narrow screens. We will check whether mobile session length and bounce rate improve in the next report.

How far we trust the data

  • Small sample: the comparison after the redesign rests on 6 visits from 3 users, so it is a direction to test, not a proven effect. We will repeat it with at least a week of data on each layout.
  • Mostly our own team: most of the 60 visits are the team and a few classmates testing, which inflates session length on desktop. We now invite outside testers so the report reflects real learners.
  • Daily buckets: Contentsquare reports page metrics by whole day, so 24 September, the day of the redesign, sits in the “before” column even though some of its visits saw the new layout.
  • Not in our plan: frustration score and error analysis are not included in our Contentsquare plan, so we cannot yet measure rage clicks or JavaScript errors.
