# Linguini transparent HD character set

The high-resolution transparent Linguini wordmark and nine PNG character
assets prepared for Canva:

1. Happy Linguini
2. Heart-eyes Linguini
3. Sunglasses Linguini
4. Farfalle friend
5. Macaroni friend
6. Noodle-ball friend
7. Rigatoni family
8. Ravioli with flag
9. Rigatoni with magnifying glass

The wordmark is saved as `00-linguini-wordmark-hd.png` at 2400 x 800.

The files use RGBA color with transparent areas. Canva accepts the PNG files
directly through **Uploads > Upload files**.
