# Linguini high-resolution Canva PNGs

This pack prioritises fidelity to the original artwork. Nothing in the two
main folders is AI-redrawn.

## Which folder should I use?

- `exact-originals-2048/` contains the original repository artwork enlarged
  to 2048 x 2048. The three Linguini mascots have transparent backgrounds.
  The six badge characters retain their original pale badge tiles so no part
  of the source artwork is changed.
- `poster-cutouts-white-2048/` contains exact crops from the supplied poster,
  enlarged to 2048 x 2048 on white. These look exactly like the characters in
  the reference image. Canva Pro's Background Remover can make them
  transparent if required.

The wordmark is supplied at 2400 x 800 with transparency in
`exact-originals-2048/`.
