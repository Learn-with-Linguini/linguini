# Linguini Canva SVG pack

Transparent, scalable SVG assets recreated for the STePS Canva artwork.

## Files

- `linguini-wordmark.svg` — standalone orange Linguini wordmark
- `01-linguini-happy.svg` — standard mascot
- `02-linguini-love.svg` — heart-eyes mascot
- `03-linguini-cool.svg` — sunglasses mascot
- `04-farfalle-friend.svg` — farfalle character on a green plate
- `05-macaroni-friend.svg` — curved macaroni character
- `06-noodle-ball-friend.svg` — noodle-ball character
- `07-rigatoni-family.svg` — three rigatoni characters
- `08-ravioli-flag.svg` — round pasta character with flag
- `09-rigatoni-magnifier.svg` — rigatoni character with magnifying glass

Each file has a transparent background and can be uploaded independently to
Canva. The SVGs are vector artwork and can be enlarged without pixelation.

Run `python generate_canva_svgs.py` from this directory to regenerate them.
